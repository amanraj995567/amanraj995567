<div align="center">

> **AI Code Assistant Platform** — *Production-grade distributed system*

```
Stack: Java · Spring Boot · Spring AI · Qdrant · MinIO · PostgreSQL
       Apache Kafka · Kubernetes · GKE · Stripe · GitHub Actions CI/CD
```

| What | How |
|---|---|
| **4-microservice architecture** on GKE | API Gateway · Account · Workspace · Intelligence Service |
| **RAG pipeline** | Chunks + embeds entire codebases → Qdrant → semantic retrieval |
| **LLM streaming** | Token-by-token via Server-Sent Events (SSE) |
| **LLM Tool Calling** | File Tree Advisors traverse MinIO workspace structures autonomously |
| **Kafka + Saga pattern** | Decouples ingestion pipeline from inference for independent scaling |
| **AI code execution** | Isolated Kubernetes pods per workspace — safe LLM-generated code runs |
| **Auth & Billing** | Spring Security JWT + multi-tenant isolation + Stripe subscriptions |
| **CI/CD** | GitHub Actions → Docker build → K8s manifest → zero-downtime GKE rollout |
